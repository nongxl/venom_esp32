-----------------------------------
# 非语言交流系统（核心新增）
-----------------------------------

当前项目：
已经具备：

- 液态毒液生物
- 自主行为
- 情绪系统
- 生理系统
- 触手附着
- 观察行为
- IMU交互
- LLM高层意识（已接入）

但当前问题：

虽然已经接入LLM，
用户仍然很难感受到：

# “它真的在思考”。

原因：

目前缺少：
# 非语言表达。

目标：

实现：

# 不依赖聊天文本
也能让用户感受到：
它具有意识、情绪与意图。

重点：

毒液：
不是聊天机器人。

它：
更像：
- 被困在设备中的生命体
- 只能通过身体和液体进行交流

-----------------------------------
# 核心原则（非常重要）
-----------------------------------

禁止：

- UI对话框
- 普通字幕
- 聊天气泡
- 直接文字回复

必须：

# 用“身体行为”
进行表达。

包括：

- 停顿
- 靠近
- 后退
- 观察
- 犹豫
- 液体书写
- 覆盖屏幕
- 触手动作
- 节奏模仿

-----------------------------------
# 非语言优先级（重要）
-----------------------------------

毒液：
默认情况下：

绝不主动说话。

大部分交流：
必须通过：

- movement
- posture
- eye movement
- tension
- breathing
- fluid expression

完成。

-----------------------------------
# 行为表达层（新增）
-----------------------------------

新增：

# Expression Layer

位于：

Emotion
↓
Intent
↓
Expression
↓
Skill

之间。

-----------------------------------
# Expression类型
-----------------------------------

实现：

-----------------------------------
## 1.
观察表达（Observe Expression）
-----------------------------------

当：

用户长时间稳定观察。

毒液：

不立即躲藏。

而是：

- 眼睛持续跟随
- 身体缓慢靠近玻璃
- 呼吸减慢
- 小触手停止摆动

表现：

# “它也在观察你”。

-----------------------------------
## 2.
犹豫表达（Hesitation）
-----------------------------------

当：

毒液想靠近
但stress仍较高。

表现：

- 前进一点
- 停顿
- 后退
- 再尝试靠近

不要：

直接移动。

目标：

像：
真正警惕生物。

-----------------------------------
## 3.
害怕表达（Fear Expression）
-----------------------------------

高stress时：

表现：

- 身体收缩
- 边缘尖刺化
- 触手抓边
- 呼吸急促
- 瞳孔缩小

不要：

总是panic乱跳。

很多时候：

# 静止不动
更像恐惧。

-----------------------------------
## 4.
信任表达（Trust Expression）
-----------------------------------

长期低stress后：

表现：

- 主动贴近观察面
- 身体摊开
- 呼吸稳定
- 允许触手贴近玻璃

效果：

像：
它开始接受用户存在。

-----------------------------------
## 5.
不满表达（Discomfort）
-----------------------------------

用户持续晃动设备时：

表现：

- 明显躲避
- 远离观察面
- 身体不稳定
- 触手乱抓

如果持续：

升级到：
液体符号表达。

-----------------------------------
## 6.
好奇表达（Curiosity）
-----------------------------------

安静环境下：

毒液：

- 探出部分身体
- 只伸出眼睛
- 触手轻敲边缘
- 缓慢改变观察角度

目标：

像：
它在研究外部世界。

-----------------------------------
## 7.
模仿表达（Mimicry）
-----------------------------------

用户：

规律敲击设备
或
稳定晃动。

毒液：

会：

- 用触手重复节奏
- 用呼吸模拟节拍
- 重复相似运动模式

目标：

形成：
“它在回应”。

-----------------------------------
## 8.
警告表达（Warning）
-----------------------------------

长期强刺激后：

毒液：

突然：

- 扑向观察面
- 覆盖部分屏幕
- 液体尖刺扩散

随后：

快速后退。

目标：

形成：
“别再继续”的感觉。

-----------------------------------
## 9.
隔玻璃接触（Glass Contact）
-----------------------------------

低stress + 高attachment时。

用户长时间稳定持握设备。

毒液：

会：

缓慢将触手
移动到：
用户握持位置对应区域。

并：

轻轻贴在玻璃内侧。

目标：

形成：
“隔着玻璃接触”。

-----------------------------------
## 10.
沉默观察（重要）
-----------------------------------

实现：

# Long Silent Observation

毒液：

有时：
长时间不动。

只是：

- 眼睛缓慢移动
- 呼吸极弱
- 轻微跟随用户

目标：

形成：
“它在思考”的感觉。

-----------------------------------
# 液态符号表达（高级）
-----------------------------------

实现：

# Fluid Symbol Expression

仅在：

极强情绪下
触发。

-----------------------------------
# 表达原则
-----------------------------------

禁止：

普通UI文本。

必须：

# 使用液体本身书写。

方式：

- 喷射液滴
- 拉丝
- 液体拖尾
- metaball连接

形成：

- NO
- STOP
- ?
- 眼睛符号
- 放射状警告图形

-----------------------------------
# 表达触发条件
-----------------------------------

例如：

长期剧烈晃动设备：

stress持续升高。

毒液：

- 无法逃离
- 多次躲藏失败后

突然：

喷射液体。

在玻璃上形成：

NO

随后：

迅速缩回角落。

-----------------------------------
# 符号风格（重要）
-----------------------------------

风格参考：

《Arrival》
七肢桶语言。

要求：

- 不规则
- 活体液态
- 会流动
- 会滴落
- 会缓慢消散

不是：
UI字体。

-----------------------------------
# 表达后的余韵（重要）
-----------------------------------

表达后：

毒液：

应表现：

- 疲惫
- 紧张
- 后悔
- 警戒

不要：

立刻恢复正常。

-----------------------------------
# 反应延迟（核心）
-----------------------------------

所有表达：

必须：

感知
↓
观察
↓
犹豫
↓
表达

不要：
瞬间触发。

-----------------------------------
# 微表达系统（重要）
-----------------------------------

即使没有大动作：

也要持续：

- 瞳孔漂移
- 呼吸变化
- 触手轻扫
- 边缘颤动
- 局部收缩

这些：
才是真正生命感来源。

-----------------------------------
# LLM角色（重要）
-----------------------------------

LLM：

只负责：

- 高层意图
- 情绪倾向
- 长期人格
- 是否产生表达欲望

不要：

直接生成动画。

-----------------------------------
# 最终目标
-----------------------------------

用户感受到：

不是：
“会聊天的AI”。

而是：

# 一个无法说话、
只能通过身体、液体与行为
努力与外界交流的生命体。

它：

- 会观察
- 会犹豫
- 会害怕
- 会依赖
- 会表达不满
- 会尝试理解人类

并且：

偶尔会用自己的身体，
在玻璃上留下：
# 一点点“想说的话”。
