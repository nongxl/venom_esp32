-----------------------------------
# 情绪视觉化系统（Emotion Visualization Layer）
-----------------------------------

当前系统：
已经具备：

- 液态毒液主体
- Metaball形态
- 情绪系统
- 自主行为
- 麦克风输入
- 环境响应

下一阶段目标：

实现：

# 情绪直接改变身体形态。

不是：
UI表情。

不是：
emoji。

而是：

# 生物身体本身的变化。

目标：

让用户：
即使不看文字，
也能感受到：

- 它紧张
- 它害怕
- 它愤怒
- 它好奇
- 它痛苦
- 它平静

-----------------------------------
# 核心原则（非常重要）
-----------------------------------

禁止：

- emoji
- 卡通表情
- UI状态提示
- 简单颜色闪烁

必须：

# 情绪通过：
形态 + 张力 + 噪波 + 节奏
表现。

-----------------------------------
# 情绪驱动形态（核心）
-----------------------------------

情绪：
必须直接影响：

- 表面噪波
- 边缘活性
- 呼吸节奏
- 张力
- 尖刺生成
- 液丝稳定性
- 局部扰动
- Voronoi结构

-----------------------------------
# Voronoi情绪层（核心）
-----------------------------------

实现：

# Voronoi/Tessellation Organic Surface

用于：

模拟：

- 生物组织
- 细胞结构
- 神经扰动
- 活体纹理

-----------------------------------
# Voronoi用途
-----------------------------------

Voronoi：
不要作为静态贴图。

必须：

# 动态演化。

并受：

- 情绪
- 声音
- 张力
- 行为状态

影响。

-----------------------------------
# 情绪影响Voronoi结构
-----------------------------------

-----------------------------------
## Calm
-----------------------------------

Voronoi：

- 平滑
- 缓慢流动
- 大块区域
- 边缘柔和

效果：

像：
平静呼吸的活体组织。

-----------------------------------
## Stress
-----------------------------------

Voronoi：

- 高频裂变
- 边缘抖动
- 小块快速变化
- 局部破碎

效果：

像：
紧张神经活动。

-----------------------------------
## Fear
-----------------------------------

Voronoi：

- 收缩
- 边缘尖锐
- 不稳定塌陷
- 黑色区域扩张

效果：

像：
组织痉挛。

-----------------------------------
## Anger
-----------------------------------

Voronoi：

- 尖刺放射
- 快速扩张
- 裂纹状传播
- 高对比扰动

效果：

像：
攻击性神经网络。

-----------------------------------
## Curiosity
-----------------------------------

Voronoi：

- 局部聚焦
- 某一区域活跃
- 纹理向观察方向流动

效果：

像：
注意力集中。

-----------------------------------
# 麦克风情绪映射（核心）
-----------------------------------

实现：

# Audio Reactive Emotion Surface

麦克风输入：
不是直接控制动画。

而是：

# 影响毒液神经状态。

-----------------------------------
# 音频频段分离（重要）
-----------------------------------

至少分离：

- Low
- Mid
- High

-----------------------------------
## Low Frequency
-----------------------------------

控制：

- 主体脉动
- 质量起伏
- 呼吸强度

效果：

像：
内部器官震动。

-----------------------------------
## Mid Frequency
-----------------------------------

控制：

- Voronoi活性
- 局部组织波动
- 触手抽动

-----------------------------------
## High Frequency
-----------------------------------

控制：

- 尖刺
- 边缘颤动
- 神经抽搐
- 微小液滴

效果：

像：
受刺激神经反应。

-----------------------------------
# 情绪惯性（重要）
-----------------------------------

声音影响：
不能立即消失。

必须：

具有：

- 累积
- 衰减
- 残留

例如：

突然巨响后：

即使声音结束。

毒液：
仍会：

- 长时间紧张
- 表面持续抽动
- 呼吸不稳定

-----------------------------------
# 神经系统感（重要）
-----------------------------------

表面变化：
不要像shader。

必须：

# 像生物神经活动。

要求：

- 局部传播
- 有延迟
- 有不规则性
- 有波传播感

-----------------------------------
# 活体组织感（重要）
-----------------------------------

表面：
必须：

像：
- 活组织
- 神经膜
- 黑色肌肉
- 液态细胞群

不要：

像：
- 水波纹
- 电子游戏特效

-----------------------------------
# 微情绪表达（高级）
-----------------------------------

即使没有大行为。

情绪：
也必须：

持续微弱影响：

- 呼吸
- 表面纹理
- 边缘活性
- 眼睛稳定度

-----------------------------------
# 眼睛情绪映射（重要）
-----------------------------------

眼睛：
不是单独UI。

必须：

和整体身体同步。

例如：

Fear：
- 瞳孔收缩
- 眼球快速微动

Calm：
- 缓慢漂移

Curiosity：
- 聚焦
- 轻微前倾

-----------------------------------
# 情绪传播（高级）
-----------------------------------

实现：

# Emotion Propagation

情绪变化：
不应瞬间影响整个身体。

而应：

从：

- 核心
或
- 接触点

逐渐扩散。

效果：

像：
神经信号传播。

-----------------------------------
# 身体区域分层（推荐）
-----------------------------------

身体：

至少区分：

- Core
- Surface
- Edge
- Tentacle
- Eye Region

不同区域：
对情绪响应不同。

-----------------------------------
# 最终目标
-----------------------------------

用户感受到：

不是：
“一个会动的特效”。

而是：

# 一个拥有真正神经活动、
内部情绪与生理反应的液态生命体。

它的身体：
本身就是：

# 情绪与意识的可视化。
