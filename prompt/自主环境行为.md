-----------------------------------
# 自主生命行为系统（新增）
-----------------------------------

即使：
- 没有LLM
- 没有联网
- 没有用户交互

毒液也必须：
# 始终像活着。

目标：

让用户感觉：
它有自己的生活。

-----------------------------------
# Autonomous Ambient Behavior
-----------------------------------

实现：
# 自主环境行为系统

毒液应持续：
- 呼吸
- 蠕动
- 微抽动
- 观察
- 贴边移动
- 局部脉动

不要：
持续大动作。

多数时间：
应保持：
- 缓慢
- 克制
- 安静

偶尔：
突然做出快速行为。

-----------------------------------
# 呼吸系统
-----------------------------------

实现：
非规则呼吸。

要求：

不要使用：
完美sin波。

应该：
- 有停顿
- 有微抽动
- 节奏不规则

-----------------------------------
# 微行为系统
-----------------------------------

增加：
Micro Behaviors

例如：

- 边缘颤动
- 局部鼓包
- 触手轻扫
- 瞳孔漂移
- 短暂尖刺
- 神经抽动

这些行为：
低幅度
低频率
随机出现。

-----------------------------------
# 惊跳行为
-----------------------------------

毒液偶尔会：

- 突然跳跃
- 快速转移
- 液滴射出
- 再重新聚合

要求：

实现：
“分裂 -> 拉丝 -> 重组”

不要真实物理。

-----------------------------------
# IMU行为响应
-----------------------------------

IMU：
不仅改变观察方向。

还影响：
- 重力
- 平衡
- 压力

例如：

轻微倾斜：
- 缓慢滑动

快速甩动：
- 惊慌收缩

倒置：
- 努力吸附
- 触手抓边

-----------------------------------
# 麦克风环境响应
-----------------------------------

不需要语音识别。

只需：
环境声音影响行为。

例如：

安静：
- 放松
- 摊开

突然大声：
- 快速收缩
- 眼睛放大

持续讲话：
- 缓慢观察声源

-----------------------------------
# 反应延迟（重要）
-----------------------------------

所有反应：
不要立即执行。

应该：

感知
→ 判断
→ 微停顿
→ 行为

这样更像真实生物。

-----------------------------------
# 行为优先级系统
-----------------------------------

实现：

高优先级行为
可打断
低优先级行为。

例如：

panic > observe > idle

-----------------------------------
# 生理参数
-----------------------------------

增加内部参数：

- energy
- stress
- curiosity
- comfort
- attachment

这些参数：
缓慢变化。

并驱动：
自主行为。

-----------------------------------
# 最终目标
-----------------------------------

即使用户什么都不做。

毒液仍然像：
# 一个真的活着的液态生物。
