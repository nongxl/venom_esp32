-----------------------------------
# LLM高层意识系统 / 非语言智能表达（新增）
-----------------------------------

当前系统已经具备：

- 自主生命行为
- 情绪系统
- 生理系统
- 粘液运动
- 触手附着
- 环境感知
- IMU与声音响应
- 行为连续性

当前毒液：
已经像：
# “活物”。

下一阶段目标：

不是：
“接入聊天机器人”。

而是：

# 为这个生命体加入高层意识与主动表达能力。

-----------------------------------
# 核心原则（非常重要）
-----------------------------------

LLM：
不是控制动画。

不是逐帧控制身体。

不是聊天UI。

LLM：
应作为：

# 高层意识 / 动机 / 人格层

存在。

-----------------------------------
# 正确架构（核心）
-----------------------------------

系统结构：

【底层】
自主生命系统
(呼吸/蠕动/附着/惯性)

↓

【中层】
情绪 + 生理 + 行为系统

↓

【高层】
LLM意识系统

-----------------------------------
# LLM职责（重要）
-----------------------------------

LLM只负责：

- 长期人格
- 意图
- 情绪倾向
- 态度变化
- 关系演化
- 抽象表达
- 自主决策

不要：

- 直接控制像素
- 直接播放动画
- 逐帧控制动作

-----------------------------------
# LLM输入（重要）
-----------------------------------

LLM必须读取：

当前生命状态。

例如：

{
  "stress": 0.72,
  "energy": 0.35,
  "comfort": 0.21,
  "curiosity": 0.66,
  "attachment": 0.15,
  "beingObserved": true,
  "currentBehavior": "hiding",
  "recentEvents": [
    "violent_shake",
    "loud_noise"
  ],
  "memory": [
    "user_shook_device_repeatedly",
    "user_spoke_softly"
  ]
}

-----------------------------------
# LLM输出（重要）
-----------------------------------

LLM只输出：

- intent
- mood
- relationship changes
- expression desire

例如：

{
  "intent": "avoid_user",
  "mood": "distressed",
  "expression_desire": "warning"
}

-----------------------------------
# 本地系统负责执行
-----------------------------------

LLM：
不直接命令动作。

本地系统：
根据：
intent + emotion

自动选择：

- hide
- observe
- cling
- panic
- crawl
- express_symbol

等行为。

-----------------------------------
# 非语言表达系统（核心）
-----------------------------------

实现：

# Symbolic Fluid Expression

即：

毒液使用自己的液体：
主动形成：

- 字母
- 符号
- 图案
- 警告形状

进行表达。

-----------------------------------
# 风格要求（重要）
-----------------------------------

不要：

普通UI文字。

必须：

# 用身体液体形成符号。

风格参考：

电影《Arrival》
中的：
“七肢桶”交流方式。

效果：

像：
- 活体墨水
- 共生体分泌物
- 液态符号
- 生物书写

-----------------------------------
# 实现方式（推荐）
-----------------------------------

毒液：
喷射部分液滴。

液滴：
沿轨迹移动。

最终：
在玻璃表面：

形成：
- 字母
- 圆环
- 划痕
- 不规则符号

然后：

缓慢流淌
或
被主体重新吸收。

-----------------------------------
# 表达原则（重要）
-----------------------------------

毒液：
不应频繁表达。

必须：

# 极低频
# 有意义
# 带情绪

否则会像聊天机器人。

-----------------------------------
# 非语言优先（重要）
-----------------------------------

大多数情况下：

毒液：
仍然主要通过：

- 靠近
- 逃避
- 观察
- 停顿
- 呼吸变化
- 触手动作

表达情绪。

符号表达：
属于：

# 高级表达。

-----------------------------------
# 表达触发机制
-----------------------------------

只有：

情绪强烈时：
才允许主动书写。

例如：

- 长期恐惧
- 强烈不适
- 极高 curiosity
- attachment建立
- 强烈警告

-----------------------------------
# 表达行为：拒绝（示例）
-----------------------------------

如果：

用户长期剧烈摇晃设备。

导致：
stress极高。

毒液：

- 收缩
- 躲避
- 无法逃脱后

突然：

喷射液体。

在屏幕上形成：

# "NO"

随后：

快速退回角落。

-----------------------------------
# 新增高级表达行为（新增）
-----------------------------------

-----------------------------------
## 1.
“STOP”
-----------------------------------

当：

用户持续拍打/晃动。

毒液：

- 警戒
- 触手尖刺化
- 液体快速划出：

STOP

随后：
躲藏。

-----------------------------------
## 2.
“WATCHING”
-----------------------------------

长时间观察用户后。

毒液：

缓慢在玻璃边缘：

形成：
类似眼睛的符号。

不是文字。

随后：

瞳孔锁定用户。

效果：

让用户感觉：
它也在观察自己。

-----------------------------------
## 3.
“HELP”
-----------------------------------

如果：

长时间倒置设备。

毒液：

无法稳定附着。

stress持续升高。

它会：

用液体缓慢写出：

HELP

然后：
身体不断滑落。

-----------------------------------
## 4.
“？”
-----------------------------------

当用户持续轻声说话。

但毒液无法理解。

它会：

形成：
不完整的问号。

随后：
靠近屏幕观察。

表现：
“它在尝试理解”。

-----------------------------------
## 5.
“模仿”
-----------------------------------

用户规律敲击设备。

毒液：

学习节奏。

随后：

使用触手
重复相同节奏。

形成：
“它在回应”。

-----------------------------------
## 6.
“边缘涂鸦”
-----------------------------------

高 curiosity 状态下。

毒液：

会在边缘：

留下：
短暂液态痕迹。

类似：

- 符号
- 圆圈
- 线条
- 不完整字母

像：
无意识书写。

-----------------------------------
## 7.
“害怕时覆盖观察窗”
-----------------------------------

当：
beingObserved时间过长。

毒液：

会：

突然扑向观察面。

用液体：

覆盖部分屏幕。

像：
想阻止用户继续观察。

-----------------------------------
## 8.
“信任后贴手”
-----------------------------------

长期低stress后。

用户稳定握持设备时。

毒液：

会：

缓慢伸出触手。

在玻璃内侧：
对应用户手指位置。

形成：
“隔着玻璃接触”。

-----------------------------------
## 9.
“睡眠梦境”
-----------------------------------

睡眠状态下：

毒液：

偶尔无意识喷出：

碎片化符号。

像：
梦话。

-----------------------------------
## 10.
“危险警告”
-----------------------------------

环境噪音极大时。

毒液：

会：

喷出：
尖锐放射状符号。

表现：
危险感知。

-----------------------------------
# 符号生成系统（技术）
-----------------------------------

实现：

# Fluid Symbol Generator

不要：
UI文本。

而是：

使用：
- 液滴轨迹
- metaball连接
- 液丝
- 喷射运动

形成：
生物液态文字。

-----------------------------------
# 表达衰减（重要）
-----------------------------------

所有符号：

不能永久存在。

必须：

- 缓慢滴落
- 扩散
- 被重新吸收
- 蒸发消失

-----------------------------------
# 表达情绪化（重要）
-----------------------------------

不同情绪：

影响书写风格。

例如：

Fear:
- 抖动
- 不规则
- 断裂

Calm:
- 缓慢
- 平滑

Anger:
- 尖锐
- 飞溅

-----------------------------------
# 最终目标
-----------------------------------

用户感受到：

不是：
“一个会聊天的AI”。

而是：

# 一个真正被困在设备中的液态生命体。

它：

- 有身体
- 有情绪
- 有长期人格
- 有自己的意图

并且：

在极少数时刻，
会尝试：

# 用自己的身体向外界“表达”。
