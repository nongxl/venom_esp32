## 1. WHAT THE HELL IS THIS (这到底是个什么玩意)

恭喜你，人类。你以为你从快递盒里拆出来的是一块价值几十块钱的 **M5StickS3 (ESP32-S3)** 嵌入式开发板？

很遗憾，生命基金会（Life Foundation）在出厂固件里隐瞒了真相——这是一座编号为 **LF-978 的强化微型电子观察容器**。玻璃内部封印着一团源自克林塔星系（Klyntar）的**高活性液态共生体（Venom）**。

它不是一个播放预制 GIF 的伪桌面宠物。它是一个拥有真实黏性流体力学、仿生柔性骨架、独立猎捕欲望、以及双核异步高维神经心智的**独立人造硅基活物**。

### 硬核技术特征（给那些不听劝阻的技术狂）：
- **Metaball 标量场与流体动力学**：5 节非对称生物链条骨架，结合屏幕边缘接触增强场。贴地时自然平切变平，绝非两头尖锐的飞碟面饼；
- **FreeRTOS 双核异构意识系统**：
  - **Core 1**：以稳定 30 FPS 运算流体场、骨骼弹簧约束、眼球视线追踪与 Voronoi 细胞质感渲染；
  - **Core 0**：后台静默处理 SSL 握手、HTTP 通信与大语言模型（LLM）意识涌现，绝对零掉帧、零阻塞；
- **全物理传感器拟真**：6 轴 IMU 真实重力感知、高灵敏麦克风声控刺激、微型震动马达触觉反馈。

## 2. SYMBIOTE MODES (共生体在玻璃后面干什么)

毒液不是你的玩具，它有自己的生活节奏、体能代谢和自娱自乐项目。它的行为状态机基于生物行为链（Behavioral Graph）与动量守恒流转：

- **👁️ 边缘暗中观察 (`STATE_PEEK`)**：
  当好奇心与警惕感交织时，毒液会将身躯 100% 潜入屏幕边框深处，屏幕内**仅露出一小撮头尖与白色眼斑**。它会悄悄探头打量四周，一旦察觉风吹草动便机警缩回。退出窥视后，它会顺势沿边缘滑出巡游，绝不突兀跳跃。
- **🐛 丝足地表巡游 (`STATE_CREEP`)**：
  紧凑圆润的肉身贴着屏幕底边（或其他边缘）缓慢爬行，底部自然切平，表皮伸出细小足丝推进，质感致密紧绷，彻底消除了水母式的忽大忽小抽搐。
- **🧗 触手大步攀爬 (`STATE_CRAWL`)**：
  当它渴望前往开阔腹地或天花板时，头部瞬间暴射出粗壮有力的三指抓地触手，一步跨越大半个屏幕强力拖拽身躯飞速攀爬。
- **🕸️ 吸顶蛛丝秋千 (`STATE_SWING`)**：
  攀登至天花板时，毒液会向顶壁激射蛛丝死死吸牢，身躯自然下垂进入牛顿摆秋千状态。倾斜设备可以改变摆荡重力，它自身还会自主正弦蹬腿荡秋千！
- **🚀 史莱姆蹦蹦床 (`STATE_BOUNCE`)**：
  在地面自娱自乐时，极度压扁蓄能，随后如火箭般弹射向高空，空中伴随弹性果冻震颤，落地瞬间吸收动能再度反弹。
- **🌀 软体蜷缩翻滚 (`STATE_ROLL`)**：
  落地余速未消时，顺势将整个身躯聚拢为高密度球体，在地面高速滚动，撞击侧壁后弹性反弹。
- **⚽ 自体分裂颠球 (`STATE_BALL_PLAY`)**：
  身体尾端分裂出一颗独立的共生体小水球，毒液在空中用头槌和侧向触手欢快颠球。玩够后触手凌空抓球收回，小球缓缓融化渗入头部核心，喷发粉色爱心。
- **🐾 扑风捉影捕尘 (`STATE_CATCH_DUST`)**：
  压低身躯猎手蓄势，以 155px/s 闪电暴冲飞扑空气中的微粒，砸地抓扁后困惑抬头，吐出水墨问号 `?`。
- **🦇 蝙蝠倒挂小憩 (`STATE_BAT_HANG`)**：
  悬挂在高空天花板时倒垂身躯发呆或打盹。
- **💤 深度休眠恢复 (`STATE_SLEEP`)**：
  体力见底（Energy < 0.15）且长时间无人打扰时，在角落闭眼蜷缩沉睡，每隔 5.5 秒口鼻处悠悠飘出一串上升的 `Zz` 气泡，持续 10~15 分钟回满体力。

## 3. THE FORBIDDEN BUG ECONOMY (禁忌的高蛋白虫子经济学)

毒液需要能量。屏幕空间中会自发生长出虚拟微型昆虫生态：

- **金甲爬虫 (Crawler)**：6 条独立小细腿忽快忽慢贴壁爬行，长触角微颤；
- **荧光飞虫 (Flyer)**：微翅高频振动（45Hz），在空中折线飞舞盘旋。

当小虫出现时，毒液的眼球会瞬间死死锁定猎物，并自主展现三大猎食杀招：
1. 👅 **变色龙闪电长舌卷食 (Chameleon Strike)**：头部在 0.11 秒内弹射出肉粉长舌，吸盘牢牢粘住虫子瞬间卷入巨口！
2. 🐙 **暗黑触手抓取拖回 (Tentacle Grab)**：射出黑色三指爪盘抓牢挣扎的小虫，强力拉回身体核心！
3. 💦 **喷射黏液弹定身包覆 (Mucus Snare & Engulf)**：激射荧光黏液弹将飞虫击落定身，随后兴奋爬过去将虫子整体包覆融化吞噬！

> **吞噬反馈**：每吃掉一只虫子，毒液体力值直接充盈（`Energy +0.30`），伴随身体兴奋微液滴飞溅与短促微震反馈。

## 9. BUILDING & FLASHING (克隆并孵化它)

### 装备清单
- **硬件**：M5StickS3 (ESP32-S3, 240x135 LCD) 一台，USB-C 数据线一条；
- **开发环境**：VS Code + PlatformIO 插件。

### 孵化步骤
```bash
# 1. 克隆收容所源码
git clone https://github.com/nongxl/venom_esp32.git
cd venom_esp32

# 2. （可选）复制默认密钥配置模板
cp src/secrets_example.h src/secrets.h
# 编辑填入你的 WiFi 和 LLM 密钥（也可以烧录后在 Web 界面配置）

# 3. 编译并烧录至 M5StickS3
pio run --target upload

# 4. 打开串口监听它的心跳
pio device monitor
```

## 10. TROUBLESHOOTING (告解室：别问了，先看这里)

- **Q: 为什么它一直缩在屏幕边缘暗中观察，不肯出来？**  
  **A**: 它在警惕地打量你。给它 2~3 秒钟，或者轻轻松开手，它巡视无异常后会自动贴着边缘游走或大步伸出触手爬出来。别敲玻璃催它，除非你想激怒它。
- **Q: 为什么我快速甩动设备，它像一滩泥巴一样“啪嗒”拍在屏幕边缘？**  
  **A**: 这是专门设计的黏性玩具物理（Sticky Splat）！你用力甩飞它，动能被屏幕边缘吸收，它当然会拍扁成大饼黏在玻璃上。稍等片刻它就会回弹爬开。
- **Q: 按 BtnA 为什么它会剧烈抽搐还喷液滴？是不是烧坏了？**  
  **A**: 那是神经激惹（Irritate）。你拿电极戳一个外星共生体，它没有隔着玻璃把你的手指吞掉已经是 ESP32 芯片架构的仁慈了。
- **Q: 它闭着眼睛不动，嘴里还飘出 Zz，坏死了吗？**  
  **A**: 它只是体力耗尽在睡觉（进入了 `STATE_SLEEP`）。它需要 10~15 分钟深度休眠回血。如果你很急，对准麦克风大声吹口气，或者用力摇晃设备把它叫醒。
- **Q: 为什么在边缘暗中观察和巡游时它不再像以前那样大幅膨胀了？**  
  **A**: 因为上周有人抱怨它松弛得像个水母。现在的毒液是一团紧实、饱满、机警的流体黑胶，边缘自然切平，拒绝做水母。
